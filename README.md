# Lockdown to Production: My Engineering Journey

It started back during COVID-19 with a simple [Coursera](https://www.coursera.org/) course in HTML, CSS and JavaScript. That first exposure to web development hooked me instantly, prompting me to dive deeper into Java and Advanced Java right before graduating.

Fresh out of college, I joined a start-up running on a Spring, Angular, MySQL stack. That environment was a turning point. Through hands-on projects and the guidance of great mentors, I hit the ground running by mastering Spring, Spring Boot and Spring Security. More importantly, that was where I truly honed my debugging skills by tracing issues smoothly from the client side all the way down to the server.

When the company needed to upgrade our legacy AngularJS app to Angular v8, I picked up TypeScript and modern Angular on the fly, building on top of my core web fundamentals. I also took ownership of integrating and documenting Liquibase for database management.

As I pursued my master’s degree, I expanded into backend scalability and infrastructure by learning Docker and diving into Microservices architecture. On the frontend side, I researched and documented Micro-frontends using Module Federation.

Today, my core focus is simple: building secure, scalable APIs that solve real, painful problems.
